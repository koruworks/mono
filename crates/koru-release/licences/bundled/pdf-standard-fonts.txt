Component: PDF standard-font substitutes (Foxit Type 1 fonts from PDFium)
Version: as embedded by hayro-font 0.5.0
Source: https://crates.io/crates/hayro-font/0.5.0 (assets/, extracted from PDFium; https://pdfium.googlesource.com/pdfium/)
Files: koru-read-worker (compiled in, through hayro-font's embed-fonts feature)
License: BSD-3-Clause
Note: Fourteen Type 1 fonts (FoxitSans, FoxitSerif, FoxitFixed and their styles, FoxitSymbol, FoxitDingbats) that stand in for the PDF standard fonts when a file does not embed them, so the read worker can map their glyphs to text. The text below is hayro-font's assets/LICENSE_FOXIT with its comment markers removed.
Platforms: windows, macos, linux
